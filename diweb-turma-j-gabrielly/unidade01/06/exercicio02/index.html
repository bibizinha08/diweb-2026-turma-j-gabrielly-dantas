Trabalhando com HTML e CSS

Para estilizar parágrafos, o CSS permite alterar o tamanho, tipo de letra, cor e diversas outras propriedades para estilização de textos.

Podemos alterar o tamanho do texto com propriedade (font-size), que possui valor padrão de 16 px (pixel).

Temos a propriedade (font-family) que permite alterar o tipo de letra utilizada no texto. Tem como valor padrão "Times New Roman".

Todas as propriedades podem ser alteradas ou modificadas conforme necessidade.
